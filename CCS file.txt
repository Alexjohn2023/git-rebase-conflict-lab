🪣 3. S3 Configuration
Step 3.1 — Create the S3 Bucket

Bucket name: alexandernjokufoundation.org

⚠️ The bucket name must exactly match the custom domain name.

Step 3.2 — Enable Static Website Hosting

Navigate to:
S3 → alexandernjokufoundation.org → Properties → Static website hosting

Settings:

Enable Static website hosting

Host a static website

Index document: index.html

Error document: error.html (optional)

Bucket website endpoint:
http://alexandernjokufoundation.org.s3-website-us-east-1.amazonaws.com

⚠️ The S3 website endpoint only supports HTTP, not HTTPS.

Step 3.3 — Make Objects Public

Update bucket policy to allow CloudFront access:

{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "PublicReadForGetBucketObjects",
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::alexandernjokufoundation.org/*"
    }
  ]
}

☁️ 4. CloudFront Configuration
Step 4.1 — Create CloudFront Distribution

Origin Settings:

Parameter	Value
Origin Domain Name	alexandernjokufoundation.org.s3-website-us-east-1.amazonaws.com
Protocol	HTTP Only
Port	80
Origin Path	(empty)

If you use HTTPS or an incorrect S3 endpoint, CloudFront will return a 504 Gateway Timeout.

Step 4.2 — Default Behavior Settings
Setting	Value
Viewer Protocol Policy	Redirect HTTP → HTTPS
Allowed Methods	GET, HEAD
Cached HTTP Methods	GET, HEAD
Cache Policy	CachingOptimized
Compress Objects Automatically	Yes
Origin Request Policy	None (unless dynamic)
Step 4.3 — SSL Certificate

Under General → Custom SSL Certificate, choose:

Certificate from AWS Certificate Manager

Security policy: TLSv1.2_2021

TLSv1.3_2025 was initially used but caused “protocol_version” errors.
TLS 1.2 ensures compatibility across all browsers.

Step 4.4 — Alternate Domain Names (CNAMEs)
alexandernjokufoundation.org
www.alexandernjokufoundation.org

Step 5.2 — WWW Subdomain Record
Name	Type	Value	Routing	TTL
www.alexandernjokufoundation.org
	A (Alias)	d2q7cyyr9zfw7v.cloudfront.net	Simple	300

Avoid using a CNAME for the apex domain — CloudFront requires an Alias A record.

Step 5.3 — Validation Records

Leave any _acm-validation CNAMEs untouched — they are needed for SSL renewal.

🔁 10. Optional Enhancements
🔹 Redirect www → Apex

Create a CloudFront Function:

function handler(event) {
  var request = event.request;
  var host = request.headers.host.value;
  if (host === 'www.alexandernjokufoundation.org') {
    return {
      statusCode: 301,
      statusDescription: 'Moved Permanently',
      headers: {
        "location": { "value": "https://alexandernjokufoundation.org" }
      }
    };
  }
  return request;
}

🔹 Add Security Headers

🧠 11. Key Takeaways
Lesson	Explanation
Exact DNS strings matter	Even one typo breaks origin resolution
S3 website endpoints only support HTTP	HTTPS must terminate at CloudFront
Always use us-east-1 for CloudFront SSL certificates	Required by ACM
TLS policy compatibility	Use TLSv1.2_2021 for full client support
Health checkers = your best diagnostic tool	They show true global connectivity status
